Chatbot básico que recibe mensajes del usuario y responde directamente desde el navegador.

- **JavaScript**
- **HTML5**
- **CSS3**

## ✨ Características

- Interfaz de conversación sencilla
- Respuestas automáticas según el mensaje del usuario
- Lógica del chatbot escrita en JavaScript

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/Ryujin010/EBAC-chatbot-simple.git
cd EBAC-chatbot-simple
```

Luego:

1. Abre el archivo `index.html` en tu navegador (doble clic), o
2. Usa la extensión **Live Server** de VS Code: clic derecho sobre `index.html` → *Open with Live Server*.
